# YouCode Events

## Présentation du projet
YouCode Events est un site web qui centralise les événements organisés par YouCode : ateliers, conférences, hackathons et rencontres avec des professionnels. Il permet aux utilisateurs de découvrir les événements, consulter leurs détails et s'inscrire en ligne.

## Objectifs
- Présenter les événements de YouCode.
- Faciliter les inscriptions en ligne.
- Créer un site moderne, responsive et accessible.
- Travailler en équipe avec Git et GitHub.

## Technologies utilisées
- HTML5
- CSS3 (Flexbox, Grid et Media Queries)
- Figma
- Git et GitHub

## Pages du site
- Accueil
- Événements
- Intervenants et partenaires
- Inscription
